Ollamaを試す

2026-09-06

自分のパソコンでローカルLLMを手軽に実行できるOllamaというのがあるそうなので試したみた。ドキュメントを読むとOllamaをインストールして実行するだけで良いようだ。使用感を試すだけなので提供されているコンテナを利用した。

コンテナを開始する

podman run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

利用可能なモデルの中から軽量なllama3.2:1bを実行してみる。

モデルの実行

podman exec -it ollama ollama run llama3.2:1b
(省略) 
>>> こんにちは
こんにちはです！どういたしまして。何がしたいと思いますか？
>>> /bye

1Bパラメータなので複雑なことはできないが、チャットができることを確認できた。他のモデルを試してみれば、どのくらいのパラメータを実用的に使えるか調べられそうだ。CLI Referenceを参照すると他のAIエージェントも使えるようだ。

後片付け

podman exec –it ollama rm llama3.2:1b
podman stop ollama
podman rm ollama
