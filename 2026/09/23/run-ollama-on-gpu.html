GPUでOllamaを実行する

2026-09-23

Ollamaを使用すると、CPUで処理されているためか動作が重く感じられる。モデルgemma4:e4bに質問「Why is the sky blue?」をすると、スループットは6.12 tk/sであった。動作状態を確認するとPROCESSOR項目がCPUで、プロセスもGPU 0%となっていた。

>ollama ps
NAME          ID              SIZE      PROCESSOR    CONTEXT    UNTIL
gemma4:e4b    c6eb396dbd59    9.4 GB    100% CPU     4096       4 minutes from now

CPUではなくGPUで処理できれば、より早くなると思われる。調べてみると、OllamaでもGPU動作可能であったので調査内容を備忘録として残しておく。

実行環境は次の通りである。

  • Windows 11 Pro
  • Intel Core Ultra 7 165H
  • Intel Arc Graphics

Ollamaのバックエンドとして使われるllama.cppを調べると、Intel GPUをサポートしていることが分かった。どうすれば良いのかとソースコードからビルドしてみたりと、いろいろと試してみたところ、サーバーログに情報があった。

>ollama serve
...
level=INFO source=runner.go:405 msg="dropping integrated GPU; to enable, set OLLAMA_IGPU_ENABLE=1" id=0 library=Vulkan compute=0.0 name=Vulkan0 description="Intel(R) Arc(TM) Graphics" pci_id=""
...

環境変数を設定してOllamaを起動する。

>set OLLAMA_IGPU_ENABLE=1
>ollama serve

動作状態を確認するとPROCESSOR項目がGPUで、プロセスもGPU 90%台になっていることが確認できた。

>ollama ps
NAME          ID              SIZE      PROCESSOR    CONTEXT    UNTIL
gemma4:e4b    c6eb396dbd59    3.5 GB    100% GPU     32768      3 minutes from now

同じモデルで質問したところスループットは14.45 tk/sまで上がり2倍以上の改善が見られた。
